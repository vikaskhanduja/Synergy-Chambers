A modern, high-performance, and fully responsive website for **Synergy Chambers**, headquartered at Chamber No. 238, Patiala House Courts, New Delhi, with regional chambers across Chandigarh and Haryana.

## ⚖️ Key Practice Areas
- **Civil Litigation:** Commercial recovery, injunctions, specific performance, partnership disputes.
- **White-Collar Crimes & Regulatory Defence:** PMLA, SFIO, ED summons, NDPS Act trials, FEMA, Customs, EOW.
- **Criminal Litigation & Trial Advocacy:** Regular & anticipatory bail, trial management, POSCO, Section 482 CrPC / BNSS quashing.
- **Arbitration & Alternative Dispute Resolution (A.D.R.):** Section 9 interim relief, Section 11 arbitrator appointments, Section 34 challenges, domestic arbitration.
- **Service Matters & Administrative Law:** CAT Principal Bench & Chandigarh Bench, promotions, pensions, disciplinary inquiries.
- **Property & Real Estate Disputes:** Title suits, partition claims, eviction, HRERA and Delhi RERA.
- **Matrimonial & Family Law:** Mutual & contested divorce, maintenance, custody, family settlements.
- **Labour & Employment Law:** POSH compliance, industrial disputes, service agreements.
- **Corporate & Commercial Advisory:** NCLT insolvency proceedings, startup structuring, contracts.

## 💻 Tech Stack
- **Framework:** React 18 & TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS (Custom Navy, Gold, and Charcoal design system)
- **Icons:** Lucide React
- **Animations:** Framer Motion & CSS keyframe transitions
- **SEO & Compliance:** JSON-LD `LegalService` Structured Data, Bar Council of India (BCI) Rule 36 compliance modal, XML Sitemap, and robots.txt.

## 🚀 Getting Started

### 1. Clone Repository
```bash
git clone https://github.com/vikaskhanduja/synergy-chambers.git
cd synergy-chambers
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Visit `http://localhost:5173` in your browser.

### 4. Build for Production
```bash
npm run build
```
Generates optimized static assets in the `dist/` directory.
